# Java Proxy with Wiremock Stub Generation

This project is a Spring Boot application that acts as a proxy, forwarding incoming HTTP requests to a configurable target URL. It includes an Aspect-Oriented Programming (AOP) feature that intercepts these requests and their corresponding responses to generate and save [Wiremock](http://wiremock.org/) stub definitions to your local filesystem.

This tool is useful for developers who want to quickly create mock stubs from live API traffic for testing or local development purposes.

## Features

- **HTTP Proxy**: Forwards all incoming requests to a configured backend service.
- **Wiremock Stub Generation**: Automatically creates Wiremock-compatible JSON stubs from live traffic.
- **Custom Annotation**: Use the `@RecordWiremock` annotation to selectively enable recording for specific controller endpoints.
- **File-based Stubs**: Saves generated stubs as `.json` files in a `wiremock` directory.
- **Configurable Target**: Easily change the proxy's target URL via the `application.properties` file.

## Requirements

- Java 17 or later
- Maven 3.6 or later

## How to Run

1.  **Clone the repository** (or use the existing source code).

2.  **Build the project** using Maven. Open a terminal in the project root and run:
    ```bash
    mvn clean install
    ```

3.  **Run the application**:
    ```bash
    mvn spring-boot:run
    ```
    The proxy server will start on `http://localhost:8080` by default.

## How to Use

The core feature of this application is the `@RecordWiremock` annotation. By adding this annotation to a controller method, you enable automatic stub generation for any requests that are handled by that method.

1.  **Annotate a Controller Method**:
    In your Spring `@RestController`, import and add the `@RecordWiremock` annotation to any method you wish to record. The proxy is already configured with a catch-all endpoint that is annotated.

    *Example from `ProxyController.java`*:
    ```java
    import com.example.javaproxy.aspect.RecordWiremock;
    import jakarta.servlet.http.HttpServletRequest;
    import org.springframework.http.ResponseEntity;
    import org.springframework.web.bind.annotation.RequestMapping;
    import org.springframework.web.bind.annotation.RestController;

    @RestController
    public class ProxyController {

        // ... service injection

        @RecordWiremock
        @RequestMapping("/**")
        public ResponseEntity<String> proxy(HttpServletRequest request) {
            // Proxying logic
        }
    }
    ```

2.  **Make a Request**:
    With the application running, make an HTTP request to the annotated endpoint. For example, using `curl`:
    ```bash
    curl http://localhost:8080/your/api/endpoint
    ```
    The proxy will forward this request to the configured `proxy.target-url`.

3.  **Find the Generated Stub**:
    After the request is complete, a new JSON file will be created in the `wiremock` directory in the project's root. The filename is generated based on the request method and a hash of the request URI (e.g., `GET_1234567.json`).

## Configuration

To change the backend service that the proxy forwards requests to, modify the `proxy.target-url` property in the `src/main/resources/application.properties` file.

```properties
# The URL of the backend service you want to proxy to
proxy.target-url=https://httpbin.org
```

After changing this value, restart the application for the new target URL to take effect.

## Example Stub

Here is an example of a Wiremock stub that was generated by making a `GET` request to `http://localhost:8080/get`.

**File**: `wiremock/GET_1502407.json`

```json
{
  "request": {
    "method": "GET",
    "url": "/get"
  },
  "response": {
    "status": 200,
    "body": "{
  "args": {}, 
  "headers": {
    "Accept": "*/*", 
    "Accept-Encoding": "gzip, x-gzip, deflate", 
    "Host": "localhost", 
    "User-Agent": "curl/8.7.1", 
    "X-Amzn-Trace-Id": "Root=1-2345-abcdefg"
  }, 
  "origin": "123.45.67.89", 
  "url": "https://localhost/get"
}
"
  }
}
```

This JSON file can be placed in the `mappings` directory of a running Wiremock instance to mock the captured API interaction.
